# Graduation kit (end-to-end)

This folder is a single review surface for the Book 4 receipt chain.

Workflow:
1) Read `witness_matrix.md`.
2) Validate inputs/contracts (contract + strict decode).
3) Validate plan/execution (cloud plan + pack bundle).
4) Validate reality (deploy snapshot + verify report).
5) Validate safety (ops guardrails + change review).

Everything is designed for **names-only review**.
